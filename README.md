## 🚀 How to Run & Preview

1. **Directly in Browser**:
   - Double-click `index.html` in your file explorer, or right-click `index.html` and choose **Open with Google Chrome** (or Edge/Brave/Firefox).
2. **With a Local HTTP Server (Optional)**:
   ```bash
   # From the Portfolio directory
   npx serve .
   # or
   python -m http.server 8080
   ```
   Then navigate to `http://localhost:8080` in your web browser.

## 🖼️ Replacing the Profile Picture

A professional portrait has already been generated and saved to `assets/profile.jpg`. If you want to use your own personal picture:
1. Save your photo as `profile.jpg`.
2. Paste it into the `assets/` folder, replacing the current `profile.jpg`.
3. Refresh your browser (Ctrl + F5).
